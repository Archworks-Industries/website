# Archworks Industries brand assets

These are the canonical vector assets for the current Archworks identity.

- `archworks-mark.svg` - Jet mark for light backgrounds
- `archworks-mark-reverse.svg` - Sand mark for dark backgrounds
- `archworks-lockup-horizontal.svg` - Outlined horizontal logo for light backgrounds
- `archworks-lockup-horizontal-reverse.svg` - Outlined horizontal logo for dark backgrounds
- `archworks-social-card.svg` - Editable vector source for the social preview

The lockup letterforms are outlined paths with no font dependency. Preserve each asset's aspect ratio and clear space. Use the reverse files on dark or photographic backgrounds.
